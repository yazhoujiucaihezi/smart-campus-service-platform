# 智慧校园综合生活服务平台

基于 Spring Boot + MyBatis + MySQL + Redis 开发的智慧校园综合生活服务平台，面向校园生活服务场景，提供用户服务、服务项目、服务分类、服务组合、订单管理及运营管理等功能。

## 项目简介

本项目采用前后端分离的开发模式，后端基于 Spring Boot 构建，使用 MyBatis 完成数据访问，MySQL 负责业务数据持久化，并结合 Redis 对高频访问数据进行缓存。

项目主要包含用户端和管理端两部分：

- 用户端：用户登录、服务项目浏览、服务组合查看、购物车、订单提交、订单查询等
- 管理端：用户管理、服务分类管理、服务项目管理、服务组合管理、订单管理等
- 数据处理：分页查询、多表关联查询、缓存处理及业务数据统计

- 服务分类管理
- 服务项目管理
- 服务组合管理
- 订单管理

## 项目特点

### 用户认证

使用 JWT + 拦截器实现用户身份认证与接口访问控制，对不同角色的访问权限进行校验。

### 数据访问

使用 MyBatis 完成业务数据的增删改查、分页查询及多表关联查询。
